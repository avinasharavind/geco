# IECO from ECMWF's own ensemble tracks, 2018–2026

IECO = the GECO construction (member shapes × k(τ) × σ̂ around HCCA as issued, full spread) on the 50 perturbed IFS-ENS members, using ECMWF's own tracker output: the BUFR track files on the AWS open-data mirror (public in real time; 2023 on, all four runs) and NHC's archived copies of the same tracks (EE01–50) before. Newest run at least 6 h old (6 h at every cycle from 2023; 12–18 h before). k(τ) refit leaving the scored season out for 2018–24; 2025–26 use k fit on 2018–24. No gridded data.

Yardsticks: dressed HCCA (HCCA as a Gaussian with its per-lead RMS error from the other 2018–24 seasons) and FNV3 at early timing (newest run 6–24 h old; 2025–26 only). GECO is shown for reference: it is IECO's twin (GEFS shapes), not a competitor. Identical cases within each table, leads 12–120 h every 12 h, all cycles; best track (2026: working best track). Fair CRPS in kt; `*` = 95% storm-block bootstrap CI excludes 0. Coverage = share inside the 10–90% range (ideal 0.80).

### GECO/IECO

GFS Ensemble Corrected Output

IFS Ensemble Corrected Output

This repository holds code for two tropical cyclone (TC) model intensity correction systems, GECO and IECO. Using a relatively simple correction technique, the original ensemble members for these global, low-resolution numerical weather prediction ensembles are corrected to be physically consistent with the TC itself. In testing, its results are on par with Google DeepMind's FNV3 forecast system, providing a new tool for forecasters to examine the variability in a tropical cyclone's forecast intensity.

As a note, this project was also my first substantial work using LLM coding agents (specifically Claude Code). The goal of this project was both to develop this product and to become familiar with the strengths and shortcomings of LLM coding agents.
